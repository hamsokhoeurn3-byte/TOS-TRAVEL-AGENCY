# Hotel image folders

Each hotel has a folder named with its app slug. Use `hotel` for property photos
and `rooms` for room type photos.

Example:

```text
hotels/golden-temple-residence/hotel/main.jpg
hotels/golden-temple-residence/rooms/deluxe-suite.jpg
```

Files here are served by Laravel from the public web root. The first example is
available at `/hotels/golden-temple-residence/hotel/main.jpg`.
